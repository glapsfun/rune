# Quickstart: Agent Context Prep (`[context]`)

**Feature**: 021-agent-context-prep | **Date**: 2026-08-21

Runnable scenarios proving the feature end-to-end. Contracts:
[contracts/context-attribute.md](contracts/context-attribute.md); shapes:
[data-model.md](data-model.md).

## Prerequisites

- Docker running (tests execute in the harness, never on the host)
- Repo root; `go run ./cmd/rune` stands in for an installed `rune`

## 1. Full verification suite

```sh
docker-compose run --rm test go test ./...
```

Expected: PASS across parser, analyzer, formatter, cli, mcpserver,
integration, and docs packages — includes every scenario below as automated
coverage.

## 2. Author a context hook

`Runefile` in a scratch directory:

```rune
# Gather project health for agents.
[context]
health:
    @echo "branch: $(git branch --show-current 2>/dev/null || echo none)"
    @echo "demo-marker"

# Show recent history.
logs:
    @git log --oneline -3
```

Validate + run by name (the hook stays a normal CLI task):

```sh
go run ./cmd/rune --list     # health is listed (not private)
go run ./cmd/rune health     # prints the health lines
```

## 3. MCP instructions on initialize

```sh
{ printf '%s\n' \
  '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"probe","version":"0"}}}'; \
  sleep 1; } | go run ./cmd/rune mcp 2>/dev/null | head -1
```

(The `sleep` keeps stdin open long enough for the response to flush.)

Expected: the JSON response's `result.instructions` contains `demo-marker`.
Also verify `tools/list` (append the corresponding request) does **not**
contain a `health` tool, while `logs` is present.

## 4. Agent-executor prompt prefix

Add to the same Runefile:

```rune
set agent_cmd := ["sh", "-c", "printf '%s' \"$1\"", "stub"]

# Echo the prompt the provider would receive.
triage (agent):
    Summarize recent work.
```

```sh
go run ./cmd/rune triage
```

Expected stdout, in order: `## Project context (generated by Runefile
[context] task)`, the health lines with `demo-marker`, `## Task`, and
`Summarize recent work.`

## 5. Degrade path (never blocks)

Change the hook body to `@exit 3` and rerun `go run ./cmd/rune triage`.

Expected: exit 0; stdout contains `(context hook "health" failed; proceeding
without project context)`; Rune's stderr carries one warning line.

## 6. Static misuse diagnostics

Declare a second `[context]` task and run any command (e.g. `--list`).

Expected: exit 3, `RUNE2007` error naming both tasks, nothing executed.
