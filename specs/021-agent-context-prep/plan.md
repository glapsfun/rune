# Agent Context Prep (`[context]`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `[context]` task attribute whose output Rune gathers and injects into agent context — as MCP server `instructions` and as an agent-executor prompt prefix — before the agent chooses or runs any task.

**Architecture:** One new attribute flows through the existing pipeline: parser accepts it, analyzer validates it (singleton, unattended-safe), and a small `gatherContext` helper on the existing `mcpAdapter` runs the hook through the same masked `Call` path agents already use. The two agent surfaces consume the helper: `ServeMCP` passes the text as MCP `ServerOptions.Instructions` (fixed at server construction — the SDK has no per-session instructions hook), and `executeAgent` prepends it to the provider prompt.

**Tech Stack:** Go, `github.com/modelcontextprotocol/go-sdk v1.6.1`, existing internal packages (`ast`, `parser`, `analyzer`, `diag`, `cli`, `mcpserver`).

**Spec:** `specs/021-agent-context-prep/spec.md`

## Global Constraints

- Tests run **inside Docker, never on the host**: `docker-compose run --rm test go test ./<pkg>/...` (per CLAUDE.md; standalone `docker-compose`, not the compose plugin).
- Commits: never add `Co-Authored-By` or "Generated with Claude Code" lines.
- Timeout and size cap are compile-time constants: 10 seconds, 8 KiB (`8 * 1024` bytes). No new flags, env vars, or config entries (NFR-002).
- Fixed prompt delimiters, verbatim: `## Project context (generated by Runefile [context] task)` and `## Task` (FR-003).
- Fallback notice, verbatim format: `(context hook %q failed; proceeding without project context)` with the task name (FR-005).
- Existing Runefiles without `[context]` must parse, analyze, and format byte-identically (NFR-001) — no change to any existing golden file.
- All diagnostics for `[context]` misuse reuse the existing code `diag.CodeInvalidAttribute` ("RUNE2007"); no new diagnostic code.

```go
// checkContext enforces the [context] hook contract (spec 021 FR-001,
// FR-007): at most one context task in the composed file, and the hook must
// be runnable unattended — no [confirm], no parameter without a default,
// and not itself an agent task (which would recurse into an agent session).
func (a *analyzer) checkContext() {
	var first *ast.Task
	for _, t := range a.file.Tasks {
		attr := t.Attr(ast.AttrContext)
		if attr == nil {
			continue
		}
		if first != nil {
			d := diag.Diagnostic{
				Severity: diag.Error,
				Span:     attr.Span(),
				Message:  fmt.Sprintf("duplicate [context] task %q (already declared on %q)", t.Name, first.Name),
				Code:     diag.CodeInvalidAttribute,
				Related:  []diag.RelatedLocation{{Span: first.Sp, Message: first.Name}},
			}
			a.diags.Add(d)
			continue
		}
		first = t
		if t.Attr(ast.AttrConfirm) != nil {
			a.diags.Codef(diag.CodeInvalidAttribute, attr.Span(), "[context] task %q cannot use [confirm]: the hook runs unattended", t.Name)
		}
		if t.Executor == ast.ExecAgent {
			a.diags.Codef(diag.CodeInvalidAttribute, attr.Span(), "[context] task %q cannot use the agent executor", t.Name)
		}
		for _, p := range t.Params {
			if p.Kind == ast.ParamRequired || p.Kind == ast.ParamVariadicPlus {
				a.diags.Codef(diag.CodeInvalidAttribute, p.Sp, "parameter %q of [context] task %q must have a default: the hook is invoked with no arguments", p.Name, t.Name)
			}
		}
	}
}
```

```go
package cli

import (
	"context"
	"fmt"
	"io"
	"strings"
	"time"

	"github.com/rune-task-runner/rune/internal/ast"
)

// Context-hook processing limits (spec 021 NFR-002): fixed, no configuration
// surface. contextTimeout is a var only so tests can shrink it.
var contextTimeout = 10 * time.Second

const contextMaxBytes = 8 * 1024

// contextTask returns the file's [context] task when one exists and is
// available on goos; an OS-mismatched hook is treated as absent (FR-008).
func contextTask(f *ast.File, goos string) *ast.Task {
	if f == nil {
		return nil
	}
	for _, t := range f.Tasks {
		if t.Attr(ast.AttrContext) != nil && t.AvailableOn(goos) {
			return t
		}
	}
	return nil
}

// gatherContext runs the [context] hook through the adapter's masked Call
// path and returns the processed text plus whether a hook exists. The hook
// is best-effort: failures and timeouts degrade to a one-line notice and a
// stderr warning (FR-005) — never an error, never a blocked surface.
func (a *mcpAdapter) gatherContext(ctx context.Context, stderr io.Writer) (string, bool) {
	t := contextTask(a.file, a.goos)
	if t == nil {
		return "", false
	}
	cctx, cancel := context.WithTimeout(ctx, contextTimeout)
	defer cancel()
	res, err := a.Call(cctx, t.Name, map[string]string{})
	if err != nil || res.ExitCode != 0 {
		fmt.Fprintf(stderr, "warning: context hook %q failed; proceeding without project context\n", t.Name)
		return fmt.Sprintf("(context hook %q failed; proceeding without project context)", t.Name), true
	}
	out := strings.TrimRight(res.Stdout, "\n")
	if len(out) > contextMaxBytes {
		// Masking already happened inside Call, so truncation cannot split
		// an unmasked secret across the cap boundary.
		out = out[:contextMaxBytes] + "\n[truncated]"
	}
	return out, true
}
```

```go
// buildAgentPrompt assembles the provider prompt: when the [context] hook
// produced text it is prepended under fixed delimiters (spec 021 FR-003);
// with no hook the body passes through unchanged (FR-009).
func buildAgentPrompt(contextText string, hasContext bool, body string) string {
	if !hasContext {
		return body
	}
	return "## Project context (generated by Runefile [context] task)\n" +
		contextText + "\n\n## Task\n" + body
}
```

```go
func (e *engine) executeAgent(task *ast.Task, lines []shell.Line, dir string, env []string) error {
	var body strings.Builder
	for _, ln := range lines {
		body.WriteString(ln.Text)
		body.WriteByte('\n')
	}

	opts := agent.Options{
		AgentCmd: e.settings.AgentCmd,
		Dir:      dir,
		Env:      env,
		Stdin:    e.opts.Stdin,
		Stderr:   e.opts.Stderr,
	}

	var contextText string
	var hasContext bool
	if e.file != nil {
		if adapter := e.newAgentAdapter(); adapter != nil {
			// Fresh project context per invocation (spec 021 FR-003); the
			// callback endpoint below reuses the same adapter, whose Tasks()
			// already excludes the [context] hook.
			contextText, hasContext = adapter.gatherContext(e.ctx, e.opts.Stderr)

			token := randomToken()
			srv := mcpserver.New(adapter, mcpserver.Options{AllowDestructive: false, Version: e.opts.Version})
			if addr, stop, err := srv.StartHTTP(mcpserver.HTTPConfig{Addr: "127.0.0.1:0", Token: token}); err == nil {
				defer stop()
				opts.MCPURL = "http://" + addr
				opts.MCPToken = token
			}
		}
	}

	finalText, err := agent.CLIProvider{}.Run(e.ctx, buildAgentPrompt(contextText, hasContext, body.String()), opts)
	if err != nil {
		return err
	}
	if finalText != "" {
		fmt.Fprint(e.opts.Stdout, finalText)
		if !strings.HasSuffix(finalText, "\n") {
			fmt.Fprintln(e.opts.Stdout)
		}
	}
	return nil
}
```

```go
func TestContextPrefixReachesAgentPrompt(t *testing.T) {
	dir := writeRunefile(t, contextRunefile)
	r := run(t, dir, nil, "triage")
	if r.code != 0 {
		t.Fatalf("exit = %d; stderr=%s", r.code, r.stderr)

	for _, want := range []string{
		"## Project context (generated by Runefile [context] task)",
		"ctx-marker-branch-main",
		"## Task",
		"Summarize the last commits.",
	} {
		if !strings.Contains(r.stdout, want) {
			t.Errorf("prompt missing %q; stdout=%q", want, r.stdout)
		}
	}

func TestContextHookFailureStillRunsAgent(t *testing.T) {
	failing := strings.Replace(contextRunefile, "@echo ctx-marker-branch-main", "@exit 3", 1)
	dir := writeRunefile(t, failing)
	r := run(t, dir, nil, "triage")
	if r.code != 0 {
		t.Fatalf("agent task must survive a failing hook: exit=%d stderr=%s", r.code, r.stderr)
```

````markdown
## Project context for agents

Mark one task with `[context]` to hand agents the project's current state — branch,
dirty files, lint findings — *before* they choose a task:

```rune
# Gather project health for agents.
[context]
health:
    @git branch --show-current
    @git status --short
    @golangci-lint run --fast || true
```

- **MCP sessions** receive the task's output as the server `instructions` in the
  initialize result, computed once at server start.
- **`(agent)` tasks** get the output prepended to their prompt, fresh on every
  invocation.

The hook is best-effort and can never block agent access: it runs under a 10-second
timeout, and on failure or timeout the agent proceeds with a one-line notice instead.
Output is capped at 8 KiB and passes through the same [secret masking](how-to/secret-masking.md)
as every other agent-facing surface. A failing health check (like `golangci-lint`
finding errors) fails the task under normal semantics — append `|| true` to deliver
the findings as context instead. The hook itself is never exposed as a tool; it stays
runnable by name from the CLI for debugging.
````
